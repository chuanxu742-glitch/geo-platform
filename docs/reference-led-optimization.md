# 从参考网站提炼 SEO / GEO 工作流

外部参考站不是当前运营品牌。不得将其直接写入正式项目、继承其资质或发布到该站。本功能使用常见页面结构问题设计通用检查能力，测试数据为合成示例。

## 已实现

- 页面观察保留 canonical、hreflang、base 标签及源位置；检查跨页规范链接、多重声明、无效链接、语言对应冲突和子页面指向语言首页的可疑配置。
- 相对网址依照最终抓取网址和 base 解析；仅分析字符串，不访问标签目标。跨页 canonical 不自动视为错误，语言首页提示不替代目标正文/双向链接检查。
- 新快照在原 fetch_evidence JSON 保存元数据，无需迁移。历史快照不重写，重新抓取后产生新检查结果。
- Agent 冻结至多40条当前快照发现，计划输入增加客户场景、路线、费用、案例、资质与效果验收指导。实际智能输出质量仍需真实模型验证。
- 页面优化区显示网站代码修复提示，并复用原发现创建任务入口。当前 WordPress 正文发布不能修改 canonical、hreflang 或网站模板。

## 运营用法

登记真实自有品牌和网站 → 抓取既有页面 → 从技术发现创建负责人任务 → 按真实订单选择客户问题 → 由 Agent 提出有来源的内容改稿 → 人审与发布 → 重新抓取及同条件复测。

路线页模板：直接答案、适用条件、准备步骤、费用构成、经授权的真实案例、已核对官方依据及日期、咨询入口。没有资料时保留缺口。新页面创建、站外更新、模板修复需各自执行路径，不能用已有正文授权代替。

## 当前边界

页面优化区已提供本项目最新成功快照的重复标题对比，可点击进入页面处理；它不是全站爬取或历史证据冻结审计。尚未提供站长工具收录接入、询盘/订单归因、参考站独立管理界面、自动新建路线页或网站源码修改适配。GEO和SEO效果仍需真实数据观察。
