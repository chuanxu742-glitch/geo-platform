# Development roadmap

## Available

- Evidence-backed page observations, canonical/hreflang checks and immutable snapshots.
- Project-level repeated-title review using latest successful page snapshots.
- Goal → reviewed plan → draft → explicit publication → full-body verification.
- Frozen baseline/retest evidence and conservative outcome reporting.

## Next

1. Server-side cross-page SEO audit with frozen comparison evidence, duplicate descriptions and task links.
2. Reference-site records separate from owned websites and approved brand facts.
3. Route/service content briefs based on actual customer questions and reviewed sources.
4. Search Console and lead/conversion evidence imports with explicit provenance.
5. Real-model and real-CMS acceptance, plus PostgreSQL runtime validation.

Issues and pull requests should target one reviewable increment. Feature availability
does not imply measured search rankings, AI recommendations or business growth.
